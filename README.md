# GENESIS Tutorial Materials

This repository contains the essential files required to follow the tutorials
for [GENESIS](https://github.com/genesis-release-r-ccs/genesis), a molecular
dynamics (MD) simulation software.

Please navigate to the directory corresponding to the chapter you are currently
studying.  Follow the instructions provided there, browse or modify the relevant
files, and run the appropriate commands as needed.

If you have any questions or find any errors, feel free to open [an issue in this
repository](https://github.com/genesis-release-r-ccs/genesis_tutorial_materials/issues).  
We welcome discussions, questions, and suggestions of any kind!
